# Kiwoom AI Trading

An independent open-source project for AI-assisted quantitative trading and systematic market research using Python, Kiwoom Securities APIs, and Model Context Protocol (MCP).

## Overview

This project aims to bridge AI agents and the Korean financial market through reproducible research and modular trading infrastructure.

## Project Scope

- Kiwoom REST API and MCP integration
- Historical and real-time market data collection
- Technical indicator and feature engineering
- Systematic strategy backtesting
- VWAP and volume-based market analysis
- Risk management and position sizing
- Historical market replay and paper trading
- AI-assisted strategy research

## Research Principles

- Reproducible experiments
- Prevention of look-ahead bias and data leakage
- Realistic transaction cost modeling
- Out-of-sample strategy validation
- Separation of research and live execution

## Project Status

Early-stage public repository based on ongoing independent development and quantitative research. Source components will be published incrementally.
